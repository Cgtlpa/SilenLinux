# Silen Linux

> Reliable by default. Powerful when you want it.

Silen Linux is an independent Linux distribution focused on simplicity, stability, and performance. It aims to provide a clean experience out of the box while leaving room for users who want full control over their system.

---

## Features

- Independent Linux distribution
- Lightweight default setup
- OpenRC init system
- Simple installer
- Built for everyday use and customization

---

## Installation

1. Download the latest ISO from the Releases page.
2. Write it to a USB drive.
3. Boot from the USB.
4. Follow the installer.
5. Reboot into Silen.
6. Its that simple :p

---

## Project

Silen is developed with a simple goal, create a distribution that works reliably without unnecessary complexity, while remaining flexible enough for users who want to build on top of it.
